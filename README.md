# tadimadz.com

Personal site for Tadiwanashe Madzivire, in the spirit of
[patrickcollison.com](https://patrickcollison.com): a name, a short bio, and
plain lists of the things that matter — books read (with ratings) and writing.

## Structure

- `index.html` — hand-edited homepage (bio is a placeholder; refine it there).
- `books.html`, `writing.html` — **generated, do not hand-edit.** Regenerated by
  `scripts/sync.py` from Goodreads and Substack.
- `data/medium.json` — hand-curated list of Medium posts (Medium blocks
  scrapers, so add new Medium pieces here by hand).
- `data/books.json`, `data/substack_posts.json` — last fetched snapshots,
  committed so the site can be rebuilt offline.
- `.github/workflows/sync.yml` — refreshes the two generated pages twice a
  week and commits any changes; can also be run manually from the Actions tab.

## Regenerate locally

```sh
python3 scripts/sync.py            # fetch fresh data and render
python3 scripts/sync.py --offline  # render from committed data/ snapshots
```

No dependencies beyond the Python 3 standard library.

## Book colour-coding

Green = five stars ("particularly great"), blue = four stars ("substantially
above average"), everything else unstyled — after Patrick Collison's bookshelf
convention, driven by Goodreads star ratings.
